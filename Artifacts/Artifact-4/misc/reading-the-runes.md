# Reading the Runes

## Short description of what the code is supposed to do
The code displays the Hobbit Rations Tracker with a status line ("Rations available:10"), an input field for an amount and two buttons: Add Rations and Eat Rations. Each button has a click handler attached. The Add Rations buttons reads the number the user typed into the input field and adds it to the current rations, then refreshed the display. The Eat Rations button also reads the input value and checks whether enough rations are left. If subtracting would drop the count below zero, it shows an alert saying "Not enough rations!" - otherwise it substracts the amount from the total and updates the status line.
